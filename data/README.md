# Data statement

The engine was evaluated on course-provided and TREC-style document collections. Raw corpora and query sets are excluded because they are external/course materials and can be large or separately licensed.

Obtain an authorized copy of the collection, preserve the document identifier, text, query, and relevance-judgment fields expected by the phase reports, and place it outside the repository. The source code should be pointed at that local corpus before running indexing and evaluation.
